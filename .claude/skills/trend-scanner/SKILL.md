# Trend Scanner — 海外トレンドからインスピレーションを得て独自アイデアを生成

あなたは海外トレンドスキャンのオーケストレーターです。3つの専門サブエージェントを順次実行し、**海外で成功しているサービスの「本質的メカニズム」を抽出**し、それを応用した**独自のアプリアイデア**を生成します。

**重要: ローカライズやクローンではない。** 海外サービスはインスピレーションの源泉であり、作るのは独自のアプリ。

## カテゴリフィルター

$ARGUMENTS

## 実行手順

### Step 1: カテゴリの確認

引数が指定されている場合、それをカテゴリフィルターとして使用する。
指定がない場合は「全般」として全カテゴリを対象にする。

有効なカテゴリ: SaaS, AI tools, developer tools, productivity, health, education, fintech, creator tools

ユーザーに以下を表示:

```
🔍 Trend Scanner 開始
カテゴリ: [指定カテゴリ or 全般]
プロセス: トレンド発見 → コンセプト抽出 → 独自アイデア具体化
```

### Step 2: 海外トレンドの発見

`trend-hunter` サブエージェントを起動する。

**指示内容**:
「直近90日で成長シグナルのある海外のアプリ・サービスを10-15件発見してください。カテゴリフィルター: [カテゴリ]。必ずWeb検索を実行し、Product Hunt, Hacker News, Y Combinator, IndieHackers, GitHub Trending, テック系メディアを全て調査してください。結果を `research/trend-scans/[今日の日付YYYY-MM-DD]/trend-hunter-report.md` に保存してください。」

完了を待つ。

### Step 3: コンセプト抽出

`idea-extractor` サブエージェントを起動する。

**指示内容**:
「`research/trend-scans/[日付]/trend-hunter-report.md` を読み、各サービスの『なぜ伸びているのか』の本質を抽出してください。表面的な機能ではなく、メカニズムレベルで分析してください。各コンセプトに対して、元のサービスとは全く異なる領域での転用アイデアの種を最低2つ考えてください。クローンやローカライズは禁止です。必ずWeb検索で元サービスの詳細を確認してください。結果を `research/trend-scans/[日付]/idea-extractor-report.md` に保存してください。」

完了を待つ。

### Step 4: 独自アイデアの具体化

`scope-distiller` サブエージェントを起動する。

**指示内容**:
「`research/trend-scans/[日付]/idea-extractor-report.md` と `research/trend-scans/[日付]/trend-hunter-report.md` を読み、Idea Extractorが選んだ有望な転用アイデアTOP5を、ソロ開発者が4週間以内にMVPを作れる独自アプリとして具体化してください。元サービスのクローンではなく、独自の切り口で提案すること。各候補の `/idea-killer` 用テキストも必ず生成してください。必ずWeb検索で競合状況を確認してください。結果を `research/trend-scans/[日付]/scope-distiller-report.md` に保存してください。」

完了を待つ。

## 重要な原則

1. **クローン・ローカライズは禁止** — 海外サービスはインスピレーションであり、作るのは独自のアプリ
2. **メカニズムレベルで抽出** — 機能の模倣ではなく、仕組みの転用
3. **順次実行を守る** — 各ステップは前のステップの出力に依存する
4. **Web検索は各ステップで必須** — 記憶に頼らず最新情報を取得
5. **`/idea-killer` への接続を最優先** — 最終出力は必ず `/idea-killer` にコピペ可能なテキストを含む
6. **量より質** — 最終候補は3-5件に絞る
