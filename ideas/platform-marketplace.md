## 1. DirectWork — 手数料ゼロ×AIマッチングのフリーランス直取引PF

- **ステータス**: 未検証（/idea-killer用テキスト生成済み）
- **MVP期間**: ~3.5週間
- **マネタイズ**: プレミアム課金 フリーランス月額¥980 / 発注者月額¥2,980
- **判定**: GO（Scope Distiller推奨Tier 3）

### 概要
クラウドソーシングの20%手数料を排除し、AIマッチングスコアで「手数料ゼロ+ミスマッチゼロ」を両立するフリーランス直取引プラットフォーム。

### インスピレーション
Novig（スポーツベッティング）の「手数料ゼロのP2Pマーケットプレイス」を、フリーランスマッチングに転用。

### ペイン
- 50万円の案件を受注しても手元に40万円しか残らない
- 手数料が高すぎて安い案件は受けられない
- 手数料ゼロのサービスはあるが、案件の質が低い・マッチングが雑

### ターゲット
フリーランスWebデザイナー/エンジニア（25-40歳）。月収30-80万円。フリーランス人口1,670万人。

### MVP機能セット
1. プロフィール登録（スキル・ポートフォリオ・希望条件）
2. 案件投稿（発注者側：概要・予算・必要スキル・期間）
3. AIマッチングスコア（相性0-100でスコアリング、双方にTOP5提示）
4. メッセージ機能（マッチ成立後のDM）
5. レビュー・評価システム（相互評価で信頼スコア蓄積）

### 技術スタック
- Next.js + Supabase (Auth + PostgreSQL + Realtime) + Vercel
- Claude API (Haiku) でマッチングスコア算出

### 競合との差別化
| 観点 | クラウドワークス | SOKUDAN | DirectWork |
|---|---|---|---|
| フリーランス手数料 | 5-20% | 0% | 0% |
| 企業側コスト | 無料 | 月額+成約費 | 無料（プレミアム¥2,980/月） |
| マッチング | 手動検索 | 手動検索 | AIスコアリング |

### 注意点
ネットワーク効果（鶏と卵問題）の壁が高い。初期ユーザー獲得に開発以上のマーケティング工数が必要。

DirectWork。フリーランス向けの「プラットフォーム手数料20%の搾取構造」を解決するAIマッチング直取引プラットフォーム。Novigの「手数料ゼロのP2Pマーケットプレイス」を応用し、「AIマッチングスコアで質を担保しつつ双方向手数料ゼロ」という切り口で提供する。コアバリューは「手数料ゼロ×AIマッチング精度」で、MVP機能はプロフィール登録、案件投稿、AIマッチングスコア、メッセージ、レビュー評価の5つ。マネタイズはプレミアム課金でフリーランス月額980円、発注者月額2,980円を想定。

## 2. Subbyx日本版 — サブスク転換プラットフォーム

- **ステータス**: 未検証（/idea-killer用テキスト生成済み）
- **MVP期間**: ~3.5週間
- **マネタイズ**: フリーミアム 月額¥2,980 + 取引手数料1.5%
- **判定**: GO（初回trend-scanner、ローカライズ型）

### 概要
個人事業主・小規模ECオーナー向けの「売り切り商品をサブスク化」する転換プラットフォーム。既存のサブスク「管理」ツールではなく「転換支援」。

### インスピレーション
Subbyx（海外で€12M ARR・EBITDA黒字化達成）の日本市場未進出ギャップ。

### ペイン
- 「定期便」「頒布会」を始めたいが仕組み作りが面倒
- 日本の既存ツールはサブスク「管理」のみで「転換支援」がない

### ターゲット
個人事業主・小規模ECオーナー

### MVP機能セット
1. サブスク商品ページ自動生成
2. Stripe決済連携（定期課金の自動処理）
3. 顧客管理画面（契約者一覧、ステータス管理）
4. 購読者向けポータル（解約・スキップのセルフサービス）
5. 基本ダッシュボード（MRR、アクティブ契約数、チャーン率）

### 技術スタック
- Next.js + Supabase + Vercel
- Stripe Billing + Checkout

### 備考
これはローカライズ型（初回scan時のアイデア）。独自アプリという方向性には沿わないが、参考として記録。

### /idea-killer用テキスト
```
Subbyxの日本語版。個人事業主・小規模ECオーナー向けの「売り切り商品をサブスク化できない」課題を解決するサブスク転換プラットフォーム。Subbyxが海外で€12M ARR・EBITDA黒字化を達成しているが、日本語版はなく、日本の既存ツールはサブスク「管理」のみで「転換支援」がない。コアバリューは「設定だけでサブスク販売ページと決済を自動生成」で、MVP機能は商品ページ生成、Stripe定期課金、顧客管理、購読者ポータル、基本ダッシュボード。マネタイズはフリーミアム+取引手数料で月額¥2,980〜を想定。
```
