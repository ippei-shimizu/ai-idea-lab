# 野球系アプリアイデア

## 1. 野球スタッツ個人通信簿

- **ステータス**: 未検証
- **MVP期間**: ~2週間
- **マネタイズ**: フリーミアム

### 概要
草野球〜社会人野球の個人プレイヤーが、自分だけの打撃・投球成績を記録・可視化する超シンプルなアプリ。「今日の打席結果を3タップで入力 → 通算成績が自動更新」。

### ペイン
- 自分の打率・出塁率を知りたいが、チームのスコアブックは紙で集計されない
- GameChangerはチーム導入が前提。個人で使えない
- 「今シーズン打率.320だった」と言いたいが根拠がない

### ターゲット
草野球〜社会人野球の個人プレイヤー（日本の草野球人口約200万人）

### 技術的特徴
- CRUD + 集計のみ。AI不要
- 最もシンプルに作れる

### 備考
ScoutBall AIの「プロ分析のアマチュア降下」コンセプトを、チーム向けではなく個人向けに転用。GameChangerが埋めていない「個人の成績管理」がガラ空き。

## 2. 草野球チーム運営アプリ

- **ステータス**: 未検証
- **MVP期間**: ~3週間
- **マネタイズ**: フリーミアム

### 概要
草野球チームの幹事が毎試合やっている出欠確認・スケジュール調整・打順編成・スコア記録を一元管理するアプリ。

### ペイン
- LINEで出欠確認 → 返事こない人にリマインド → 集計
- 対戦相手との球場・時間調整がLINEの往復で煩雑
- 打順・守備位置を毎回手動で組む
- 試合後のスコア記録 → 誰もやらない → 記録が残らない

### ターゲット
草野球チームの幹事・キャプテン（日本の草野球人口約200万人）

### 技術的特徴
- 出欠・スケジュール・打順のCRUD
- LINE Bot連携で差別化可能

### 備考
GameChangerはスコア記録特化。チーム運営の「試合の前」と「試合の後」がガラ空き。GoRout Connectの「分断データの統合ダッシュボード」コンセプトを草野球レベルに降ろす発想。

## 3. 我が子ハイライト記録アプリ

- **ステータス**: 未検証
- **MVP期間**: ~3週間
- **マネタイズ**: フリーミアム or 買い切り

### 概要
少年野球の保護者が、2時間の試合動画から「我が子の打席・守備」だけをタイムスタンプ管理し、成長アルバムとして残せるアプリ。

### ペイン
- 試合を動画で撮るが、2時間の動画から我が子の打席を探すのが地獄
- 子供の成長記録を残したいが、散在している
- 他の子と比較したいわけじゃない。「去年の自分 vs 今年の自分」が見たい

### ターゲット
少年野球の保護者（少年野球登録者数約40万人、保護者含めると100万人以上）

### 技術的特徴
- 動画タイムスタンプ管理 + アルバム形式
- AI不要でも成立（手動タイムスタンプ入力）
- 将来的にAI自動タグ付けに拡張可能

### 備考
WSC Sportsの「映像の自動構造化」コンセプトを、プロのハイライト生成ではなく「親目線の我が子記録」に転用。感情的価値が高く、口コミで広がりやすい。

## 4. 野球練習メニュー共有SNS

- **ステータス**: 未検証
- **MVP期間**: ~3週間
- **マネタイズ**: フリーミアム

### 概要
少年野球・高校野球のコーチが練習メニューを投稿・検索・評価できるプラットフォーム。料理レシピアプリの構造を野球練習に転用。

### ペイン
- 「今日の練習メニュー何にしよう」を毎日考えるのが負担
- ネットで調べても断片的。体系的な練習メニューDBがない
- 他のチームがどんな練習してるか知りたいが、閉じた世界

### ターゲット
少年野球〜高校野球のコーチ・指導者

### 技術的特徴
- レシピアプリの構造を転用（投稿・検索・評価・カテゴリ）
- UGCモデルなのでコンテンツ制作コストゼロ

### 備考
ScoutBall AIの「プロ分析のアマチュア降下」コンセプトだが、分析ではなく練習コンテンツの民主化。日本にはこの領域の定番アプリが存在しない。

## 5. UGC型一球速報アプリ

- **ステータス**: 未検証
- **MVP期間**: ~3.5週間
- **マネタイズ**: 広告 or フリーミアム

### 概要
地方の高校野球・大学野球の試合を、球場にいるファンや保護者が簡単に速報入力でき、離れた場所から試合経過をリアルタイムで追えるアプリ。

### ペイン
- 甲子園やプロは速報があるが、地方大会や大学リーグは情報がない
- 保護者やOBが球場にいるのに、情報がLINEグループに閉じている
- 「今何対何？」を知りたい人が大量にいるのに、発信手段がない

### ターゲット
高校野球・大学野球のファン、保護者、OB

### 技術的特徴
- リアルタイム通信（WebSocket/Supabase Realtime）が必要でやや複雑
- UGCモデル

### 備考
Wunderfanの「ファンの受動行動を報酬化」を転用。入力者にポイント等の報酬を与えることで速報の持続性を確保。地方大会の情報格差を埋める社会的価値。

## 海外リサーチで発見した参入可能なサービスモデル

以下は海外で成功しており、ソロ開発者でも参入可能な野球系サービスのパターン:

| サービス | コンセプト | ソロ開発者の参入方法 |
|---|---|---|
| PitchLab | スマホカメラ×AIで球速分析（34Kユーザー、個人開発成功例） | CV/ML知識があれば再現可能。スマホだけで完結 |
| ScoutBall AI | 既存データ（GameChanger）をAI分析に変換 | 既存データソースに乗る戦略。自前のデータ収集不要 |
| 3motionAI | スマホ動画からAI動作解析 | 外部資金なしで成立。特定動作に特化すればMVP可能 |
| Rithmm | 公開統計データをAI予測に変換（$29.99/月） | モデル設計が核。少人数で構築可能 |
| Wunderfan | ファンエンゲージメント×リワード | 技術自体はシンプルなWebアプリ |
