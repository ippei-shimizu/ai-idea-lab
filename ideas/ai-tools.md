## 1. NumbersNavi — 個人事業主のAI経営ナビゲーター

- **ステータス**: 未検証（/idea-killer用テキスト生成済み）
- **MVP期間**: ~3週間
- **マネタイズ**: フリーミアム 月額¥1,980
- **判定**: GO（Scope Distiller推奨Tier 1）

### 概要
freee/マネーフォワードの会計CSVデータをAIが分析し、「来月やるべきこと3つ」を自然言語で提案するナビゲーター。帳簿を「つける」ツールではなく、帳簿を「読んでアドバイスする」AI。

### インスピレーション
ScoutBall AI（野球）の「既存データをAIでプロ級インサイトに変換」を、会計データに転用。

### ペイン
- 売上は上がっているのに手元のお金が減っている気がする
- 値上げすべきか、新規営業すべきか判断できない
- 税理士は申告の時だけ。経営相談は月1回15分で終わる

### ターゲット
個人事業主・フリーランス（420万人）。年商500万-3,000万円。freee/MFで確定申告はしているがそれ以上のデータ活用はゼロ。

### MVP機能セット
1. freee/MF CSV取り込み
2. AIダッシュボード（売上推移・費用構造・キャッシュフロー予測を自動グラフ化）
3. 今月のアクション提案（AIが「来月やるべきこと3つ」を自然言語で提案）
4. チャット相談（「値上げしたらどうなる？」にAIが会計データに基づき回答）
5. 月次レポート自動生成（PDF）

### 技術スタック
- Next.js + Supabase + Vercel（無料枠）
- Claude API (Haiku/Sonnet) で推論
- Papa Parse でCSV解析、Recharts でグラフ

### 競合との差別化
| 観点 | freee / MF | NumbersNavi |
|---|---|---|
| 主機能 | 記帳・申告 | 経営判断の提案 |
| AI活用 | 仕訳自動化 | 経営アクション提案 |
| 経営示唆 | 数値レポートのみ | 自然言語で「次に何をすべきか」 |

### /idea-killer用テキスト
```
NumbersNavi。個人事業主向けの「会計データはあるのに経営判断に使えない」課題を解決するAI経営ナビゲーター。ScoutBall AIの「既存データをAIでプロ級インサイトに変換」を応用し、「freee/MFのCSVを取り込むだけでAIが来月やるべきことを提案」という切り口で提供する。コアバリューは「会計データ→経営アクション変換AI」で、MVP機能はCSV取り込み、AIダッシュボード、アクション提案、チャット相談、月次レポートの5つ。マネタイズはFreemiumで月額1,980円を想定。
```

## 2. WalkSight — 介護スタッフ向け歩行リスクAIスコアラー

- **ステータス**: 未検証（/idea-killer用テキスト生成済み）
- **MVP期間**: ~4週間
- **マネタイズ**: B2B SaaS 月額¥9,800/施設
- **判定**: GO（Scope Distiller推奨Tier 2）

### 概要
介護施設のスタッフが日常巡回中にスマホで利用者の歩行を10秒撮影するだけで、AIが転倒リスクスコアを即座に算出。経時変化を追跡し、悪化時に自動アラート。

### インスピレーション
Theia/Uplift Labs（野球）の「カメラだけでラボ級バイオメカニクス」を、高齢者の歩行分析に転用。

### ペイン
- 「あの利用者さん、最近ちょっとふらつくな」の感覚はあるが定量的に記録・共有する手段がない
- 転倒事故が起きてから「もっと早く気づけば」と後悔
- 理学療法士は月に数回しか来ない

### ターゲット
介護施設（特養・老健）の介護スタッフリーダー（30-40代）

### MVP機能セット
1. スマホ歩行撮影（廊下での日常歩行を10-15秒）
2. AIリスクスコア算出（歩行速度・ストライド長・左右対称性・ふらつき度の4指標）
3. 利用者カルテ（スコア履歴、経時変化グラフ）
4. 変化アラート（前回比で有意な悪化時に自動通知）
5. PDF報告書出力（理学療法士・家族への共有用）

### 技術スタック
- Next.js + PWA + Supabase + Vercel
- MediaPipe Pose（ブラウザ上で姿勢推定、完全無料OSS）
- カスタムスコア算出ロジック（TypeScript）

### 競合との差別化
| 観点 | CareWiz トルト | WalkSight |
|---|---|---|
| 計測方法 | 5m歩行コースを設定して撮影 | 日常の廊下歩行を撮るだけ |
| 結果時間 | 2分 | 即時（端末上推論） |
| 変化検知 | 手動で前回比較 | AIが自動検知・通知 |
| 価格 | 要問い合わせ（初期費用+月額） | ¥9,800/月（初期費用なし） |

```
WalkSight。介護施設の介護スタッフ向けの「転倒事故の予兆を見逃す」課題を解決する歩行リスクAIスコアリングアプリ。Theia/Upliftの「カメラだけでラボ級バイオメカニクス」を応用し、「日常巡回中にスマホで撮るだけで即座にリスクスコア」という切り口で提供する。コアバリューは「計測準備ゼロ×経時変化の自動アラート」で、MVP機能はスマホ歩行撮影、AIリスクスコア、利用者カルテ、変化アラート、PDF報告書出力の5つ。マネタイズはB2B SaaSで月額9,800円/施設を想定。
```
