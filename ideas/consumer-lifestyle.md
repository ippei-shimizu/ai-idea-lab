## 1. Alice日本版 — AI試験対策アプリ

- **ステータス**: 未検証（/idea-killer用テキスト生成済み）
- **MVP期間**: ~3週間
- **マネタイズ**: フリーミアム 月額¥980（学割¥580）
- **判定**: GO（初回trend-scanner推奨Tier 1）

### 概要
教材PDFをアップロードするだけで、AIが試験対策問題を自動生成・採点・解説するWebアプリ。「教材はあるがアウトプット練習素材がない」課題を解決。

### インスピレーション
Alice（海外でユーザー650%成長・$20K MRR）の日本市場未進出ギャップ。

### ペイン
- 教材はあるが「問題を解く」練習素材が不足している
- 問題集を買っても、自分の教材とリンクしていない
- アウトプット練習が圧倒的に足りない

### ターゲット
大学生・資格受験者。日本は試験大国（大学受験、資格試験、TOEIC等）。

### MVP機能セット
1. 教材アップロード（PDF/画像→OCR+テキスト抽出）
2. AI問題自動生成（選択式4択 + 記述式をLLMで生成）
3. 問題演習モード（解答→即座にAI採点・解説）
4. 間隔反復リマインダー（間違えた問題を忘却曲線で再出題）
5. 学習進捗表示（科目別正答率、弱点分野ハイライト）

### 技術スタック
- Next.js + Supabase + Vercel
- OpenAI API (GPT-4o-mini) で問題生成・採点
- pdf-parse + Tesseract.js でPDF解析

### 備考
これはローカライズ型（初回scan時のアイデア）。独自アプリという方向性には沿わないが、日本の試験文化との親和性が極めて高い。

### /idea-killer用テキスト
```

```

## 2. Habit Pixel日本版 — ピクセルアート習慣トラッカー

- **ステータス**: 未検証（/idea-killer用テキスト生成済み）
- **MVP期間**: ~2.5週間
- **マネタイズ**: 買い切り¥480 / 年額¥2,400
- **判定**: GO（初回trend-scanner推奨Tier 2）

### 概要
習慣を続けるたびにピクセルアートが1ピクセルずつ完成していく、視覚的達成感を提供する習慣トラッカー。

### インスピレーション
Habit Pixel（海外で8ヶ月で$0→$1K MRR・33Kダウンロード）の日本市場未進出。

### ペイン
- 習慣トラッカーはチェックマークや数字ばかりで味気ない
- 続けるモチベーションが続かない
- 成果が視覚的に見えない

### ターゲット
習慣化に挫折しがちな社会人・学生。日本のドット絵文化・ゲーム文化との親和性が高い。

### MVP機能セット
1. 習慣登録・デイリーチェックイン
2. ピクセルアート進捗キャンバス（チェックインするたびにドット絵が完成）
3. ストリーク・統計表示
4. リマインダー通知（PWAプッシュ）
5. 完成アート画像エクスポート（SNS共有用）

### 技術スタック
- Next.js + Supabase + Vercel + HTML Canvas API
- AI不要

### 備考
これはローカライズ型（初回scan時のアイデア）。最も開発期間が短くリスクが低い。ただしMRR規模は限定的。
