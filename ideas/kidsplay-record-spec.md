# KidsPlay Record — アプリ仕様書（ドラフト）

> 最終更新: 2026-03-29
> ステータス: 仕様検討中（未検証）

---

## 1. アプリ概要

**子供のスポーツ成績とプレー動画/写真を紐付けて管理する成長記録アプリ**

保護者が子供の試合・練習でのプレーを「成績データ + 動画/写真」でセットで記録し、時系列で成長を振り返れる。マルチスポーツ対応。

### ポジショニング

```
みてね（成長アルバム）の「スポーツ特化版」
×
スコアブックアプリの「動画紐付け版」
```

---

## 2. ターゲットユーザー

### プライマリ
- **少年スポーツの保護者**（30-45歳の父母）
- 子供がチームスポーツに参加している（野球、サッカー、バスケ、バレーボール等）
- 試合/練習で子供のプレー動画をスマホで撮る習慣がある
- 撮った動画がカメラロールに埋もれて見返せないことにストレスを感じている

### セカンダリ
- **少年スポーツのコーチ/指導者** — チーム全員の成長を把握したい
- **スポーツをする子供本人**（中高生）— 自分の成績と動画を自分で管理

## 4. 機能一覧

### 4.1 子供プロフィール管理

| 項目 | 詳細 |
|---|---|
| 基本情報 | 名前、ニックネーム、生年月日、プロフィール写真 |
| スポーツ登録 | 複数スポーツ登録可（野球+サッカー等） |
| チーム登録 | スポーツごとにチーム名、背番号、ポジション |
| 兄弟対応 | 1アカウントで複数の子供を管理可能 |
| スポーツ変更 | 過去のスポーツの記録を保持したまま新しいスポーツを追加可能 |

### 4.2 試合/練習の登録

| 項目 | 詳細 |
|---|---|
| 種別 | 試合 / 練習 / 大会 / 紅白戦 |
| 日付 | カレンダーから選択 |
| 対戦相手 | チーム名（試合の場合） |
| 場所 | テキスト入力（任意） |
| スコア | 試合結果（任意。例: 5-3 勝ち） |
| メモ | 自由メモ（天気、子供のコンディション等） |

### 4.3 プレー記録の入力

#### 共通仕様
- 1試合に複数のプレー記録を登録可能
- 各プレー記録に動画/写真を紐付け可能（0〜複数）
- 入力は3-4タップで完了する設計
- メモ欄あり（自由記述）

#### 野球テンプレート

**打撃記録（1打席ごと）:**

| 項目 | 選択肢 |
|---|---|
| 打席結果 | 安打 / 二塁打 / 三塁打 / 本塁打 / ゴロ / フライ / ライナー / 三振 / 四球 / 死球 / 犠打 / 犠飛 / エラー出塁 / フィルダースチョイス |
| 打点 | 0, 1, 2, 3, 4 |
| 得点 | あり / なし |
| 盗塁 | 0, 1, 2 |
| メモ | 自由記述（例: 「逆方向に打てた」） |

**投球記録（1登板ごと）:**

| 項目 | 入力方法 |
|---|---|
| イニング数 | 数値入力（例: 3.1） |
| 被安打 | 数値 |
| 奪三振 | 数値 |
| 四死球 | 数値 |
| 失点 / 自責点 | 数値 |
| 勝敗 | 勝 / 負 / セーブ / なし |
| メモ | 自由記述 |

**守備記録（任意）:**

| 項目 | 選択肢 |
|---|---|
| ポジション | 投/捕/一/二/三/遊/左/中/右 |
| 好プレー | あり（メモ + 動画紐付け） |
| エラー | あり（メモ + 動画紐付け） |

#### サッカーテンプレート

| 項目 | 入力方法 |
|---|---|
| ポジション | GK / DF / MF / FW |
| ゴール | 数値 |
| アシスト | 数値 |
| シュート | 数値 |
| 好プレー | あり（メモ + 動画紐付け） |
| 出場時間 | フル / 前半のみ / 後半のみ / 途中出場 |
| メモ | 自由記述 |

#### バスケットボールテンプレート

| 項目 | 入力方法 |
|---|---|
| ポジション | PG / SG / SF / PF / C |
| 得点 | 数値 |
| アシスト | 数値 |
| リバウンド | 数値 |
| スティール | 数値 |
| ブロック | 数値 |
| 好プレー | あり（メモ + 動画紐付け） |
| メモ | 自由記述 |

#### 汎用テンプレート（その他スポーツ）

| 項目 | 入力方法 |
|---|---|
| スポーツ名 | 自由入力 |
| 記録したいこと | 自由メモ |
| 好プレー | あり（メモ + 動画紐付け） |
| 数値記録 | カスタム項目（「タイム」「得点」等、ユーザーが項目名を設定） |

### 4.4 動画/写真の紐付け

| 項目 | 詳細 |
|---|---|
| 添付方法 | カメラロールから選択 / その場で撮影 |
| 添付先 | プレー記録（打席、登板、ゴール等）に紐付け |
| 複数添付 | 1プレーに対して動画/写真を複数添付可能 |
| 対応形式 | 動画: MP4, MOV / 写真: JPG, PNG, HEIC |
| 動画の長さ | 制限なし（ただしアップロード時に圧縮オプション提供） |
| サムネイル | 動画の先頭フレームを自動サムネイル化 |
| オフライン対応 | ローカルに一時保存し、Wi-Fi接続時に自動アップロード |

### 4.5 通算成績の自動集計

#### 野球
| 指標 | 算出方法 |
|---|---|
| 打率 | 安打数 / (打数 - 四死球 - 犠打 - 犠飛) |
| 出塁率 | (安打 + 四死球) / 打席数 |
| 長打率 | 塁打数 / 打数 |
| 打点合計 | 累計 |
| 本塁打数 | 累計 |
| 防御率 | (自責点 × 9) / 投球イニング |
| 奪三振率 | (奪三振 × 9) / 投球イニング |

#### サッカー
- 総ゴール数、総アシスト数、1試合平均ゴール、出場試合数

#### バスケ
- 総得点、1試合平均得点、総アシスト、総リバウンド

#### 全スポーツ共通
- 出場試合数、練習参加数、好プレー数

### 4.6 成長タイムライン

| 機能 | 詳細 |
|---|---|
| タイムライン表示 | 時系列で試合/プレー記録を一覧表示（動画サムネイル付き） |
| フィルタリング | スポーツ別、期間別、試合のみ/練習のみ |
| 「去年の今頃」比較 | 1年前の同時期の成績・動画を並べて表示 |
| 月別サマリー | 月ごとの出場数、主要成績のサマリーカード |
| ハイライトリール | 好プレーだけを集めた自動プレイリスト |

### 4.7 共有機能

| 機能 | 詳細 |
|---|---|
| プレー動画の共有 | 個別の動画をLINE/SNSに共有（成績データ付きカード画像を自動生成） |
| 成長レポートの共有 | 月次/シーズン成績をPDFまたは画像で出力 |
| 家族間共有 | 夫婦間で同じ子供のデータを共有（招待制） |

## 5. 画面構成

### 5.1 画面一覧

| 画面 | 概要 |
|---|---|
| ホーム | 子供の選択 + 直近の記録サマリー + クイックアクション |
| 子供プロフィール | プロフィール編集、スポーツ/チーム管理 |
| カレンダー | 月表示で試合/練習日を表示。日付タップで詳細 |
| 試合/練習詳細 | その日の試合情報 + プレー記録一覧 + 動画/写真 |
| プレー記録入力 | スポーツ別テンプレートでの入力画面 |
| 動画/写真添付 | カメラロール選択 or 撮影 |
| 成績ダッシュボード | 通算成績グラフ、スポーツ別タブ切り替え |
| 成長タイムライン | 時系列の全プレー記録 + 動画サムネイル |
| 成長比較 | 「去年の今頃」と現在の成績・動画を並べて表示 |
| 設定 | アカウント、通知、データエクスポート、プラン管理 |

### 5.2 主要ユーザーフロー

#### プレー記録の登録フロー
```
ホーム → [+] ボタン
→ 子供を選択（兄弟がいる場合）
→ 試合 or 練習を選択
  → 既存の試合を選択 or 新規作成
→ プレー種別を選択（打席 / 登板 / ゴール等）
→ 結果を3-4タップで入力
→ 動画/写真を添付（任意）
→ 保存
```

#### 成長を振り返るフロー
```
ホーム → 子供を選択
→ 成長タイムライン or 成績ダッシュボード
→ 特定のプレーをタップ
→ 動画再生 + 成績詳細
→ 「去年の今頃」と比較
```

## 6. 技術仕様

### 6.1 技術スタック

| レイヤー | 技術 | 理由 |
|---|---|---|
| フレームワーク | Expo (React Native) | iOS/Android同時対応、カメラロール連携 |
| ナビゲーション | Expo Router | ファイルベースルーティング |
| UI | NativeWind (Tailwind CSS for RN) | 高速UI開発 |
| 状態管理 | Zustand | 軽量、シンプル |
| 認証 | Supabase Auth | Google/Apple Sign-in |
| DB | Supabase (PostgreSQL) | RLS対応、リアルタイム |
| ストレージ | Supabase Storage | 動画/写真保存 |
| 動画圧縮 | expo-video-thumbnails + FFmpeg (expo-av) | アップロード前の圧縮 |
| グラフ | react-native-chart-kit or Victory Native | 成績グラフ |
| PDF生成 | react-native-html-to-pdf | 成長レポート出力 |

### 6.2 データモデル（概要）

```
users
├── id, email, name

children
├── id, user_id, name, nickname, birthday, photo_url

children_sports
├── id, child_id, sport_type, team_name, jersey_number, position, is_active

games
├── id, child_id, sport_type, date, type (試合/練習/大会)
├── opponent, location, score_team, score_opponent, memo

play_records
├── id, game_id, child_id, sport_type, play_type (打席/登板/ゴール等)
├── result_data (JSONB: スポーツ別の成績データ)
├── memo, is_highlight

media
├── id, play_record_id, type (video/photo), file_url, thumbnail_url
├── duration, file_size

family_shares
├── id, child_id, shared_with_user_id, permission
```

### 6.3 成績データの格納（JSONB）

`play_records.result_data` にスポーツ別のデータをJSONBで格納:

```json
// 野球・打席
{
  "type": "batting",
  "result": "single",
  "rbi": 1,
  "scored": true,
  "stolen_bases": 0
}

// 野球・投球
{
  "type": "pitching",
  "innings": 3.1,
  "hits_allowed": 2,
  "strikeouts": 5,
  "walks": 1,
  "runs": 1,
  "earned_runs": 1,
  "decision": "win"
}

// サッカー
{
  "type": "soccer",
  "goals": 1,
  "assists": 0,
  "shots": 3,
  "position": "FW",
  "play_time": "full"
}
```
