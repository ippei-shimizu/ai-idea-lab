# 少年野球・少年スポーツ向けアプリ/サービス 競合調査レポート

> 調査日: 2026-03-28
> 目的: 「我が子ハイライト記録」との差分を明確化するための網羅的競合調査

---

## エグゼクティブサマリー

調査の結果、日本国内外で少年野球/少年スポーツ向けアプリは大きく4カテゴリに分類される。

| カテゴリ | 代表サービス | 「我が子ハイライト記録」との重複度 |
|---|---|---|
| 動画ハイライト自動生成 | HaiLyts, WSC Sports | 中（汎用ツール。選手単位の切り出し機能なし） |
| チーム向け映像分析 | SPLYZA Teams, Hudl, Trace | 低（コーチ/選手向け。保護者の「我が子を見たい」ニーズ未対応） |
| 野球スコア/成績記録 | スコアラー, SCORE BASE, PLAY by TeamHub | 低（数値データ中心。動画連携なし） |
| 家族アルバム/成長記録 | みてね, STORYY | 中（動画管理あるが、スポーツ特化の文脈なし） |

**核心的発見: 「保護者が試合動画から我が子のシーンだけを自動で切り出し、成長アルバムとして蓄積する」という体験を提供するサービスは、日本にも海外にも存在しない。**

唯一の近似はTrace（米国）のPlayerCam機能だが、専用カメラ（$200+）とGPSデバイスが必要で、対応スポーツはサッカー/バスケ中心。野球、特に少年野球には非対応。GameChangerのハイライト機能も「試合全体のハイライト」であり「特定の子ども」にフォーカスしたものではない。

## 1. 動画管理・ハイライト系アプリ

---

### 1-1. HaiLyts（ハイライト）

| 項目 | 内容 |
|---|---|
| **運営** | 株式会社SPLYZA（日本） |
| **URL** | https://products.splyza.com/hailyts/ |
| **主な機能** | 動画を1つ選択 → ハイライト時間を選択 → 自動でアクティブなシーンを検出してハイライト動画を生成。画像処理技術で動きの大きなシーンを優先的に選出 |
| **ターゲット** | 個人（スポーツ、旅行、イベント等の汎用） |
| **動画管理/ハイライト** | あり（自動ハイライト生成）。ただし「特定の選手を追跡」する機能はなし |
| **価格** | 無料（App Store） |
| **評価** | 「自動でいらない部分をカットしてくれるから便利」。社会人やファミリー層の女性から人気 |
| **我が子ハイライトとの差分** | HaiLytsは「動きが大きいシーン」を汎用的に検出するだけ。「#7番の子のシーンだけ」という選手単位の切り出しは不可。成長記録としての蓄積・時系列管理もなし |

---

### 1-2. SPLYZA Teams（スプライザチームズ）

| 項目 | 内容 |
|---|---|
| **運営** | 株式会社SPLYZA（日本） |
| **URL** | https://products.splyza.com/teams/ |
| **主な機能** | チーム用映像分析ツール。動画共有、描画・コメント機能、スロー再生、タグ付けによるシーン検索。選手名タグで「選手Aのシーンだけ」を絞り込み可能 |
| **ターゲット** | チーム（コーチ・選手向け）。30種以上のスポーツ対応、約900チーム導入 |
| **動画管理/ハイライト** | タグ検索で選手別シーン抽出が可能（手動タグ付けが必要）。自動ハイライト生成はなし |
| **価格** | Basic: 539円/月（年払い）〜、月あたり40分のアップロード制限 |
| **評価** | ウインターカップ出場校など高校部活レベルで導入実績多数 |
| **我が子ハイライトとの差分** | 最も近い機能を持つが、(1)タグ付けが手動（保護者にはハードル高い）、(2)「分析ツール」であり「思い出アルバム」ではない、(3)チーム契約が前提で個人/保護者が単独で使えない、(4)少年野球の保護者層（ITリテラシー中程度）には操作が難しい |

## 6. 「我が子ハイライト記録」が突ける市場の空白

### 空白1: 「選手単位の自動切り出し」x「野球」x「日本」
- Traceが「選手単位の自動ハイライト」を実現しているが、野球非対応かつ日本未展開
- GameChangerは野球対応だが「試合全体のハイライト」であり選手単位ではない
- 日本の少年野球市場にこの機能を持つサービスは皆無

### 空白2: 「スポーツ文脈のある成長記録」
- みてね（2,500万人）は成長記録の王者だが、スポーツ文脈なし
- スコアアプリ群は数値データのみで動画なし
- 「打席に立つ我が子」「守備でファインプレーする我が子」を時系列で振り返れるアプリは存在しない

### 空白3: 「スマホ1台で完結」x「保護者向け」
- 海外サービス（Trace, BallerCam, Pixellot）は専用ハードウェアが必要
- SPLYZA Teamsはスマホ完結だがコーチ/選手向け
- 「保護者がスマホ1台で、撮った動画から我が子のシーンを切り出せる」サービスは存在しない

### 空白4: 「少年野球の保護者コミュニティ」
- 日本の少年野球人口は推定20万人以上。1チームあたり平均15-20名、保護者は2名として30-40名
- 試合のたびに保護者がスマホで動画を撮る行動は既に普遍的
- しかし、その動画を「我が子のシーンだけ切り出して保存・共有」するツールがないため、カメラロールに埋もれて見返されない
